## 1. 核心概念

### 1.1 什么是围物为心？

围物为心是一个**主观评分社区**。在这里，你可以：

- 🏷️ 创建带有**自定义维度**的评分榜单（如"最佳咖啡馆榜单"，维度：口味 / 氛围 / 性价比）
- ✍️ 作为榜单作者给出你的**作者评分**（维护主观偏好）
- 👥 让社区用户提交**社区评分**，共同完善判断
- 📊 查看**共识度**（Confidence）—— 社区意见的一致程度
- 🎨 生成精美的**分享卡**，导出 PNG 分享到社交媒体

### 1.2 三个核心理念

| 理念 | 含义 |
|------|------|
| **主观优先** | 保护榜单作者的个人偏好。系统从不声称"这是客观最好的" |
| **可解释** | 每个分数都能回答"为什么是这个分"——因为有维度、有权重、有算法 |
| **置信度 = 共识度** | UI 中称为"共识度"而非"权威分"——它衡量的是"大家有多同意"，而非"有多好" |

### 1.3 关键术语

| 术语 | 说明 |
|------|------|
| **榜单 (List)** | 一个评分主题，如"2024 年最佳华语电影" |
| **维度 (Dimension)** | 评分的评价角度，如"剧情 / 演技 / 视觉效果"，可设权重 |
| **条目 (Item)** | 被评分的对象，如某部具体电影 |
| **作者评分 (Author Score)** | 榜单创建者自己的评分 |
| **社区评分 (Community Score)** | 其他用户提交的评分 |
| **共识度 (Confidence)** | 0-100 分，衡量社区意见的一致程度 |
| **同好 (Rapport)** | 与另一位用户评分品味相似度 |

## 2. 创建榜单 (Ranker Studio)

点击导航栏**「+ 创建」**按钮进入榜单创建器，共 4 个步骤：

### 步骤 1：基本信息

| 字段 | 说明 |
|------|------|
| 标题 | 榜单名称，如"杭州独立咖啡馆 Top 10" |
| 副标题 | 一句话概述榜单的定位（可选） |
| 简介 | 更详细的背景说明（可选） |
| 封面图 | 上传榜单封面（可选） |
| 可见性 | PUBLIC（公开）/ LINK_ONLY（仅链接可访问）/ PRIVATE（仅自己可见） |

### 步骤 2：维度与权重

- 添加评价维度，如"口味 / 氛围 / 性价比 / 颜值"
- 为每个维度设置**权重**（1-5），权重越高表示这个维度越重要
- 维度决定了评分矩阵的结构

### 步骤 3：条目与算法

- 添加被评分的条目，如"Seesaw Coffee / M Stand / %Arabica"
- 选择**评分算法**：

| 算法 | 适用场景 |
|------|----------|
| 加权平均 | 默认推荐，平衡各方面表现 |
| 几何平均 | 重视短板——任一维度差则总分大幅下降 |
| Borda 排位分 | 只比排名不比绝对分，消除评分尺度差异 |
| TOPSIS 理想解 | 多维度综合决策，离理想解最近者胜 |
| 贝叶斯收缩 | 评分数量少时向均值回归，避免小样本极端 |

### 步骤 4：作者评分

- 在每个维度上给每个条目打分（1-5 分）
- 这是**你的主观评价**——没有标准答案，反映你个人的判断

### 步骤 5：发布

确认所有信息无误后点击「发布」，榜单即刻公开！

## 3. 浏览与发现

### 3.1 首页 Feed

首页展示多样性 × 高共识度 × 新鲜度的混合推荐，向下滚动可持续加载。

### 3.2 发现页 (Explore)

点击导航栏「发现」进入：

- 🔍 **搜索**：按关键词搜索榜单标题和内容
- 🏷️ **分类浏览**：按话题标签筛选
- 📱 **瀑布流布局**：快速浏览大量榜单

### 3.3 排行榜 (Leaderboard)

点击导航栏「🔥 热榜」查看当前最热门的 Top 20 榜单。

热度公式：**点赞 × 3 + 社区评分 × 2 + 评论 × 1.5 + 浏览量 × 0.1**

## 4. 评分与互动

### 4.1 给榜单评分

进入榜单详情页 → 点击「我去打分」→ 沉浸式 3 步流程：

1. 确认榜单了解程度
2. 在每个维度上打分
3. 提交评分

**注意**：
- 每个设备/账号对同一榜单**24 小时内只能提交一次社区评分**
- 过快打分（< 3 秒）会被系统降权

### 4.2 点赞 / 点踩

榜单详情页底部可进行点赞（👍）或点踩（👎），影响共识度计算。

### 4.3 评论

- 在榜单详情页评论区发表看法
- 系统自动分析评论情感倾向（正面/中性/负面）
- 可按「最新」或「最热」排序评论

### 4.4 共识度说明

共识度是 0-100 的数值，反映社区意见的一致程度。它在三个地方同时更新：

| 场景 | 含义 |
|------|------|
| 榜单详情页 | 当前榜单的社区共识水平 |
| 探索页 | 用于推荐排序 |
| 排行榜 | 影响热榜排名 |

共识度受以下因素影响：
- 参与评分的独立人数
- 社区排序与作者排序的一致性
- 评论的情感倾向
- 时间的衰减（半衰期 30 天）

## 5. 个人主页与徽章

### 5.1 个人主页

点击右上角头像 →「个人主页」可查看：
- 你创建的所有榜单
- 你的评分记录
- 你的徽章收藏
- 与你评分品味相似的同好

**别人的主页**：点击榜单作者头像或链接即可访问。

### 5.2 徽章系统

达成特定条件自动获得徽章：

| 徽章 | 获得条件 |
|------|----------|
| 🆕 初心 | 创建第一个榜单 |
| 🫸 八方共鸣 | 单榜共识度 ≥ 80 |
| 📣 众声喧哗 | 单榜参与评分 ≥ 100 人 |
| 🏆 品类开拓者 | 某分类下首个榜单 |

徽章会显示在你的个人主页和分享卡上。

### 5.3 同好关系

系统自动计算你与其他用户的评分品味相似度。在你的个人主页可看到与你最相似的用户。

在榜单详情页点击「导出」按钮进入分享卡页面。

### 6.1 选择模板（6 套）

| 模板 | 风格 |

## 7. 账户与设置

### 7.1 匿名使用

默认状态下你可以**匿名使用**核心功能——浏览榜单、提交社区评分，通过设备标识识别。

### 7.2 注册账号

在「设置」页面绑定邮箱和密码，升级为正式账号后可享受：

- 昵称

## 8. 常见问题 FAQ

### Q：我的榜单被别人恶意刷低分怎么办？

A：系统内置**反刷分检测**机制：

- ⚡ 过快打分（< 3 秒）自动降权至 0.2 倍
- 🖥️ 同设备 24h 内重复打分直接降权至 0
- 📏 评分方差异常（标准差 < 0.5）降权至 0.5 倍
- ⚠️ 极端评分（全部最高 / 全部最低）标记为待审核

### Q：我可以删除自己的榜单吗？

A：可以。在榜单详情页右上角点击 DELETE 按钮即可。

### Q：我可以删除别人的榜单吗？

A：普通用户不能。只有管理员（ADMIN 角色）有权删除任何榜单。

### Q：共识度为 0 是什么意思？

A：说明该榜单暂时没有足够多的社区评分来达成共识。随着参与人数增加，共识度会逐渐上升。

### Q：为什么有些榜单在首页看不到？

A：首页 Feed 算法综合考虑多样性、共识度和新鲜度。设为"仅自己可见"或"仅链接可见"的榜单不会出现在 Feed 中。

### Q：我可以修改已发布的榜单吗？

A：目前支持修改榜单的基本信息（标题、简介等）。条目的增删改正在开发中。

### Q：支持哪些语言？

A：目前支持**中文（简体）**和**English**，通过 URL 前缀 `/zh/` / `/en/` 切换。更多语言正在规划中。

### Q：如何报告问题或提出建议？

A：请访问我们的 [GitHub Issues](https://github.com/nous-hermes/weiwuweixin/issues) 提交 Bug 报告或功能建议。详见 [贡献指南](CONTRIBUTING.md)。

## 9. 使用技巧 💡

### 提升榜单共识度的技巧

1. **添加详细的维度说明**——帮助他人理解每个维度的含义
2. **认真填写作者评分**——作者评分是社区评分的参照系
3. **分享榜单链接**——更多参与者 = 更高共识度
4. **保持活跃**——共识度受时间衰减影响，30 天半衰期

### 创作好榜单的技巧

1. **选一个有区分度的主题**——"全世界最好吃的东西"太宽泛；"北京五道口 500 米内最好吃的麻辣烫"更有趣
2. **维度是关键**——合理设计维度让评分更有说服力
3. **给出你的真实评分**——主观不等于随便，真实的判断才有价值
