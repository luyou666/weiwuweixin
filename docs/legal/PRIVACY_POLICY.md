# 隐私政策

最后更新日期：2026 年 5 月 3 日

## 概述

围物为心（以下简称"本软件"）是一个开源的、可自部署的物品评分与共识计算平台。本软件代码基于 MIT 许可证开源，任何人都可以下载、部署和运行自己的实例。**本隐私政策适用于由软件部署者运营的具体实例**，软件开发者不直接收集、存储或处理任何用户数据。

**重要提示**：由于本软件为自部署（self-hosted）架构，部署者即为该实例的数据控制者（Data Controller）。本隐私政策作为模板供部署者参考使用，部署者应根据实际情况进行调整，并独立承担数据控制者的法律责任。

---

## 一、信息收集

### 1.1 用户主动提供的信息

在您使用本软件实例时，以下信息可能会被收集并存储在部署者的数据库中：

| 信息类型 | 具体内容 | 说明 |
|---------|---------|------|
| 设备标识 | `deviceId`（匿名设备标识符） | 用于在未登录状态下识别唯一设备，无需注册即可使用基本功能 |
| 账户信息 | 电子邮箱地址 | 通过 JWT 认证方式登录时提供 |
| 个人资料 | 昵称 | 用户自行设置的公开显示名称 |
| 内容贡献 | 发布的榜单、评分记录、评论 | 用户在平台上创作和发布的所有内容 |

### 1.2 技术自动收集的信息

当您访问本软件时，服务器可能自动记录以下技术信息：

- **IP 地址**：用于网络通信的必要技术数据
- **浏览器类型与版本**：通过 HTTP 请求头自动获取
- **访问时间与日期**：服务器日志中的时间戳记录
- **请求的页面或 API 端点**：标准的 Web 服务器日志

这些信息通常由 Web 服务器（如 Nginx、Caddy）或应用框架（Next.js、Fastify）自动记录，属于互联网服务的标准技术实践。

## 二、信息使用

收集的信息将用于以下目的：

1. **提供核心评分服务**：使您能够创建榜单、对物品评分，以及查看评分结果
2. **计算共识度**：基于多用户评分数据，计算群体共识度指标，是本软件的核心功能
3. **展示个人主页**：公开展示您的昵称、发布的榜单和评分活动（您在平台上主动发布的信息将默认公开可见）
4. **社区互动**：支持评论、讨论等社区功能
5. **技术运维**：保障服务稳定运行，排查故障，防止滥用

## 三、信息存储

### 3.1 存储方式

所有用户数据存储在部署者所控制的 **PostgreSQL** 关系型数据库中。部分会话和缓存数据可能存储在 **Redis** 中。

### 3.2 数据位置

数据存储的物理位置和地域完全取决于部署者的服务器部署位置。用户应咨询具体的实例运营者了解数据存储地点。

### 3.3 数据自控

由于本软件为开源自部署架构，任何人（包括用户本人）都可以自行部署一套独立实例，从而完全掌控自己的数据。我们鼓励对数据主权有较高要求的用户考虑此选项。

### 3.4 数据保留

数据保留期限由部署者自行决定。原则上，用户数据将一直保留至用户主动删除或因部署者维护需要而移除。

## 四、Cookie 与跟踪

### 4.1 Cookie 使用

本软件**仅使用必要的会话 Cookie**，用于：

- 维持登录状态（JWT Token 存储）
- 基本的会话管理

### 4.2 第三方跟踪

本软件**不嵌入任何第三方跟踪脚本**、不包含广告 SDK、不使用分析跟踪器（如 Google Analytics）。软件代码中不包含向第三方服务器发送用户行为数据的逻辑。

### 4.3 禁用 Cookie

您可以通过浏览器设置禁用 Cookie，但这可能导致登录功能无法正常使用。

- 检测、防止或处理欺诈、安全或技术问题

## 七、数据安全

### 7.1 安全措施

本软件实施以下安全措施：

- **密码安全**：所有用户密码使用 **bcrypt** 算法进行哈希处理后再存储，不保存明文密码
- **身份验证**：邮箱登录使用 JWT（JSON Web Token）进行安全的身份验证
- **SQL 注入防护**：通过 Prisma ORM 的参数化查询防止 SQL 注入攻击

### 7.2 部署者安全建议

我们强烈建议所有部署者：

- **启用 HTTPS/TLS**：为实例配置 SSL 证书，加密传输中的数据
- **定期备份**：定期备份数据库，防止数据丢失
- **限制访问**：妥善配置数据库和 Redis 的访问控制
- **及时更新**：保持软件依赖项和安全补丁的更新

数据安全的具体水平取决于部署者实施的安全措施。请向您所使用的实例运营者了解具体的安全实践。
